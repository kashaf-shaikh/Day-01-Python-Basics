# Day 01 - Python Basics

This is my Day 1 work from Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp.

I made two small Python projects while learning the basics of Python. Both projects take input from the user and display an output.

## Projects

### 1. Band Name Generator

This program asks the user for their city name and pet name. It then combines both names to suggest a band name.

**Example:**

```text
Hello! Welcome to our Band Name Generator

Where do you live?
Mumbai

Enter your Pet Name?
Bruno

Your band name could be Mumbai Bruno
```

### 2. Movie Recommendation Generator

This program asks the user about their favourite movie and favourite actor. It then displays a simple movie recommendation using their answers.

**Example:**

```text
MOVIE RECOMMENDATION GENERATOR

What's your Favorite Movie?
Forrest Gump

What's your Favorite Actor?
Tom Hanks

You should watch movies of Tom Hanks like Forrest Gump....
```

## What I Learned

While making these projects, I learned:

- How to use the `print()` function.
- How to take input using `input()`.
- How to store information in variables.
- How to combine strings.
- How to display user input in the output.
- How to use `\n` to move the input cursor to a new line.

## How to Run

1. Download or clone this repository.

3. Open the `main.py` file inside either project folder.
4. Run the Python file.
